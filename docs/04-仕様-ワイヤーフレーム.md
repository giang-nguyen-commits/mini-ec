# ワイヤーフレーム / Wireframe giao diện

基本レイアウトのみ。色・フォントの最終指定は実装時の Tailwind に任せる。  
Chỉ layout cơ bản. Màu sắc và font chốt lúc code (Tailwind).

関連: `03-仕様-画面.md`（要素と振る舞い）。

---

## 1. 共通ルール / Quy tắc chung

| 項目 | JA | VI |
| --- | --- | --- |
| キャンバス | モバイル 390px / デスクトップ 1024px+ | Mobile 390px / Desktop 1024px+ |
| コンテンツ幅 | 最大 960px、中央寄せ | Max 960px, căn giữa |
| ヘッダー高 | 56px（モバイル）/ 64px（デスクトップ） | 56px mobile / 64px desktop |
| 余白 | 画面左右 16px（sm+ は 24px） | Padding ngang 16px (sm+: 24px) |
| カード半径 | 8〜12px | 8–12px |
| 主ボタン | 全幅（モバイル）、自動幅（デスクトップ詳細） | Full width mobile; auto width desktop (chi tiết) |

**グリッド / Grid**

- 一覧モバイル: 1 列
- 一覧 `sm+`: 2 列
- 一覧 `lg+`: 3 列
- 詳細デスクトップ: 画像 | 情報 の 2 列（1:1）
- カート: 常に 1 列の行リスト

## 2. 共通ヘッダー / Header

```
┌──────────────────────────────────────────┐
│ Giang Cosmetic    商品一覧  ログイン  🛒 2 │
└──────────────────────────────────────────┘
```

- 左: テキストロゴ（リンク `/`）。デスクトップでは中央にロゴ、左に商品一覧 / 注文履歴
- 右: ログインまたはログアウト、カート。バッジは件数 > 0 のとき
- 下に 1px の区切り線
- `position: sticky; top: 0`

```
│ Giang Cosmetic          [Giỏ 2] │   ← 同一構造、ラベルのみ言語切替可
```

## 8. 実装時に守ること / Khi code cần giữ

1. ヘッダーは全画面で同一コンポーネント。
2. 一覧はカード全体がリンク。カード内に別ボタンを置かない（MVP）。
3. 詳細の主ボタンはファーストビュー内（モバイルでは画像の直後でも可）。
4. カートに Stripe は置かない。購入導線は「ご注文へ」→ `/checkout`。
5. 売り切れは色だけでなく文字でも示す。

**VI:**

1. Ba màn (và auth/checkout) dùng chung một header.
2. Cả thẻ danh sách là một link; MVP không thêm nút phụ trong thẻ.
3. Nút thêm giỏ nằm trong tầm nhìn đầu (mobile: ngay dưới ảnh cũng được).
4. Giỏ không nhúng Stripe. Nút «ご注文へ» tới `/checkout`.
5. Hết hàng phải có chữ, không chỉ đổi màu.
